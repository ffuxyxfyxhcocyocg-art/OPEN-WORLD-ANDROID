# Open World BR Mobile — Godot 4

Base nativa em Godot 4, separada do protótipo Android/WebView antigo.

## Incluído
- Cena 3D com iluminação e cidade low-poly gerada por código.
- Personagem provisório com colisão e câmera em terceira pessoa.
- Movimento, corrida e pulo.
- Controles de toque: joystick virtual, PULAR e CORRER.
- Renderizador Mobile para priorizar aparelhos Android modestos.

## Abrir
1. Instale Godot 4.x.
2. Importe a pasta godot/ pelo Project Manager.
3. Execute a cena principal.

## Exportar para Android
Configure os templates Android e o Android SDK/JDK no Editor Settings. Depois crie um preset Android e exporte. Este repositório ainda não contém um APK exportado.

## Estado
É uma primeira base prototípica. Ainda faltam modelos próprios, animações, interiores, otimização detalhada e integração multiplayer. O projeto antigo permanece intacto fora desta pasta.
